## 📖 О проекте

**PROGA1337** — это консольное приложение на C#, которое автоматизирует оформление практических работ по программированию. Программа читает задания из обычного текстового файла или Word-документа (.docx) и самостоятельно генерирует:

- ✅ **Готовый код на C#** с сохранением в Word-документ
- ✅ **Алгоритмические блок-схемы** в формате SVG для Microsoft Visio
- ✅ **Преобразование существующего кода** в блок-схему

Программа портативная — работает с USB-флешки на любом компьютере с Windows без установки.

---

## 🎯 Возможности

### 📝 Генерация кода по описанию задания
Программа распознаёт ключевые слова и генерирует код для различных типов задач:
- Математические вычисления (корни, степени, модули, округление)
- Работа с максимумом/минимумом (Math.Max, Math.Min)
- Геометрия (площадь, периметр, объём, диагональ)
- Тригонометрия (sin, cos, tan)
- Условные конструкции (if/else, ветвление)
- Проверка чётности, знака числа, сравнение

### 📊 Генерация блок-схем
Автоматическое создание блок-схем с правильными фигурами:
- 🔵 **Овал** — Начало/Конец (цвет: `#E6F3FF`)
- ⬠ **Параллелограмм** — Ввод/Вывод данных (цвет: `#F2F2F2`)
- ⬜ **Прямоугольник** — Действия и вычисления (белый)
- 🔶 **Ромб** — Условия if/else (цвет: `#FFF2CC`)

Все фигуры имеют чёрную обводку 2px и соединены стрелками с наконечниками.

### 🔄 Преобразование кода в блок-схему
Можно загрузить готовый код C# (.txt) и получить по нему блок-схему для Visio.

### 📁 Поддержка форматов
- **Входные файлы:** `.txt`, `.docx` (Word)
- **Выходные файлы:** `.doc` (Word), `.svg` (Visio)
